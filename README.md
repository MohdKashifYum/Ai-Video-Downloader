# Ai-Video-Downloader

A multi-module media downloader web application built with **Python**, **Streamlit**, **`yt-dlp`**, and **`imageio-ffmpeg`**.

## Features

- **Universal Downloader:** Download video (`MP4`) or audio (`M4A`) streams from supported URLs with metadata preview and direct browser download.
- **Batch Queue:** Process multiple media links sequentially from a single text area.
- **Analytics & History:** Track session download counts, formats, and recent URLs with one-click history clearing.
- **System Diagnostics:** Inspect active Python, Streamlit, and `ffmpeg` binary paths.
- **Theme Toggle:** Switch between light and dark UI modes.
